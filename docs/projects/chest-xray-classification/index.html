Chest X-Ray Multi-Class Classification

How well can deep learning models distinguish between different categories of chest X-ray images?

This project explores that question through a multi-class image classification pipeline using convolutional neural networks and transfer learning.

The Idea

Image classification problems become particularly interesting when different types of prediction errors have different implications.

I wanted to investigate how different deep learning approaches perform on a medical imaging classification task and understand the limitations of evaluating models using only overall performance metrics.

The Approach

I developed a classification pipeline for four chest X-ray categories:

  • COVID-19
  • Normal
  • Pneumonia
  • Tuberculosis

The project involved developing a convolutional neural network baseline and comparing it against a ResNet18 model using transfer learning.

The implementation used Python and PyTorch.

The Experiments

I explored different approaches to improving classification performance, including transfer learning, class weighting, and partial fine-tuning.

Model evaluation involved examining:

  • Classification performance
  • Macro F1 score
  • Per-class recall
  • Class imbalance
  • Prediction errors

What I Found

The custom CNN baseline achieved a macro F1 score of 0.829, while the ResNet18 transfer-learning approach improved this to 0.881.

However, the results also highlighted differences in performance across individual classes.

In particular, the NORMAL class had a recall of 0.547, motivating further investigation into class imbalance and prediction behaviour.

I'll expand this section with evaluation plots, confusion matrices, and a more detailed discussion of the findings.

What I Learned

This project helped me better understand how model architecture, transfer learning, and evaluation choices affect image classification experiments.

One of the most important lessons was recognising that an improvement in an aggregate metric doesn't necessarily mean the model performs equally well across every category.
