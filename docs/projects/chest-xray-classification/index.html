Chest X-Ray Classification

Exploring how deep learning models can learn to distinguish between different categories of chest X-ray images.

The Idea

I wanted to investigate how different neural network approaches perform on a multi-class image classification problem.

The project involved classifying chest X-ray images into four categories:

  • COVID-19
  • Normal
  • Pneumonia
  • Tuberculosis

The Approach

I implemented a convolutional neural network baseline and compared it against a ResNet18 model using transfer learning.

The project involved:

  • Image preprocessing
  • Training a convolutional neural network
  • Applying transfer learning
  • Handling class imbalance
  • Evaluating classification performance
  • Analysing prediction errors

What I Explored

One of the most interesting aspects was understanding why a model performs differently across classes, even when its overall evaluation metrics appear promising.

This led me to explore class-level performance, error analysis, and the limitations of relying on aggregate metrics.
