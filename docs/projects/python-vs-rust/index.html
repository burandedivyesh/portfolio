Python vs Rust: Audio Processing

How much does the choice of programming language affect the performance of the same computational task?

This question became the foundation of my Master's dissertation at Heriot-Watt University, where I investigated the differences between Python and Rust through audio feature extraction and classification.

The Idea

Python and Rust offer different approaches to software development, particularly when it comes to performance, memory management, and abstraction.

I wanted to explore how those differences translate into measurable results when both languages are used to solve a comparable problem.

The Experiment

I designed a benchmarking study around an audio feature extraction and K-Nearest Neighbours classification pipeline using the GTZAN dataset.

The experiment involved comparing Python and Rust implementations across different dataset sizes.

I evaluated:

  • Execution time
  • Peak memory consumption
  • CPU utilisation
  • Classification accuracy

The study also involved statistical analysis to investigate whether observed performance differences were significant.

What I Found

The experiments revealed statistically significant differences in computational performance between Python and Rust implementations, without significant differences in classification accuracy.

The full analysis involved examining how implementation choices, dataset sizes, and experimental conditions influenced the results.

I'll expand this section with detailed findings, visualisations, and interpretations from my dissertation.

What I Learned

This project gave me an opportunity to explore benchmarking, experimental design, statistical analysis, and the challenges of making fair comparisons between programming languages.

It also encouraged me to think more carefully about how performance should be measured and interpreted.
