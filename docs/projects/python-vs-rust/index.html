Python vs Rust: Audio Processing

How much does the choice of programming language influence the performance of the same computational task?

The Idea

For my Master's dissertation at Heriot-Watt University, I investigated this question through an audio feature extraction and classification pipeline.

I wanted to understand the differences between Python and Rust when performing comparable operations.

The Experiment

The project involved implementing audio processing and classification workflows and evaluating their behaviour across different experimental configurations.

I compared the implementations using:

  • Execution time
  • Memory consumption
  • CPU utilisation
  • Classification accuracy

The experiments also involved statistical analysis to understand the observed differences.

What I Explored

Beyond comparing two programming languages, this project gave me an opportunity to explore performance benchmarking, experimental design, and the importance of making fair comparisons.
