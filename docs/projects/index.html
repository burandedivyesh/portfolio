Static Site Generator

Building the Tool Behind This Website

I wanted to understand what happens between writing a Markdown document and seeing a finished webpage.

What began as a programming exercise during a Boot.dev course eventually became something I could put to practical use. I built a static site generator in Python, and today it powers the website you're reading.

It's far from a fully featured Markdown processor, but that's part of what makes it interesting. Every limitation presents another opportunity to understand the problem a little better.

Python vs Rust: Audio Processing

Does the Language Really Make a Difference?

Python is often valued for its simplicity and extensive ecosystem, while Rust offers a different approach to performance and memory management.

For my Master's dissertation, I wanted to explore how those differences play out when both languages are used for comparable computational tasks.

I designed a benchmarking experiment around audio feature extraction and classification, comparing execution time, memory consumption, CPU utilisation, and classification accuracy.

What interested me most wasn't simply which implementation was faster, but understanding why the differences occurred and how to measure them fairly.

Particle Swarm Optimisation

Can a Swarm Teach a Neural Network?

Neural networks are commonly trained using gradient-based optimisation, but I wanted to explore a different approach.

This project involved implementing a feed-forward neural network and a Particle Swarm Optimisation algorithm from scratch, without relying on deep-learning frameworks.

By experimenting with network architectures, swarm configurations, and optimisation parameters, I explored how a population of candidate solutions could search for better network weights.

It was an opportunity to understand optimisation from a different perspective, particularly the balance between exploration and exploitation.

Chest X-Ray Classification

Looking Beyond Overall Accuracy

Image classification becomes particularly interesting when the consequences of different types of prediction errors matter.

In this project, I explored a four-class chest X-ray classification problem using deep learning.

I developed a convolutional neural network baseline and compared it with a ResNet18 model using transfer learning.

One of the most valuable parts of the experiment was looking beyond overall performance and investigating where the models struggled, particularly when evaluating individual classes.
