Static Site Generator

What happens between writing Markdown and seeing a finished website?

I built a simple static site generator that converts Markdown into HTML, and I'm now using it to power this very portfolio. It's an ongoing project and a way for me to explore how web technologies work behind the scenes.

Python vs Rust: Audio Processing

How much does the choice of programming language affect the performance of the same task?

For my Master's dissertation, I explored this question by comparing Python and Rust implementations of an audio feature extraction and classification pipeline.
