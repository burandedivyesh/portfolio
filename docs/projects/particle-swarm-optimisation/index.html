Particle Swarm Optimisation for Neural Network Training

What if we tried training a neural network without relying on traditional gradient-based optimisation?

The Idea

This project explores Particle Swarm Optimisation as an alternative approach to training a neural network.

Rather than relying on existing deep learning frameworks, I implemented the neural network and optimisation algorithm from scratch using Python.

The Experiment

I experimented with different network architectures and swarm configurations to understand their effects on model performance.

The project involved:

  • Implementing a feed-forward neural network
  • Building a Particle Swarm Optimisation algorithm
  • Experimenting with network architectures
  • Comparing optimisation configurations
  • Evaluating regression performance

What I Explored

The project helped me investigate the balance between exploration and exploitation in optimisation algorithms, as well as the challenges of designing controlled experiments.
