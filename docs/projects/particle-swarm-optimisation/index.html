Particle Swarm Optimisation for Neural Network Training

Can a neural network be trained without relying on traditional gradient-based optimisation?

This project explores that question by implementing a neural network and a Particle Swarm Optimisation algorithm from scratch.

The Idea

Neural networks are commonly trained using gradient-based methods such as backpropagation with gradient descent.

I wanted to investigate a different approach: using a population-based optimisation algorithm to search for suitable network parameters.

Particle Swarm Optimisation takes inspiration from the collective behaviour of groups, where individual particles explore a search space while sharing information about promising solutions.

The Approach

I implemented a feed-forward neural network and a Particle Swarm Optimisation algorithm using Python, without relying on deep-learning frameworks.

The project focused on a concrete-strength regression problem.

I experimented with:

  • Different neural network architectures
  • Swarm sizes and configurations
  • Optimisation coefficients
  • Exploration and exploitation behaviour
  • Regression performance

The Experiments

I designed experiments to understand how different configurations affected the performance of the optimisation process.

The investigation included comparing network architectures and observing how swarm behaviour changed under different parameter settings.

I'll expand this section with the experimental configurations, performance results, and visualisations.

What I Learned

This project helped me explore the relationship between optimisation algorithms and neural network training.

It also provided an opportunity to understand the challenges of implementing algorithms from scratch and evaluating them through controlled experiments.
