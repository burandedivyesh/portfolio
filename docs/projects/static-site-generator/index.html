Static Site Generator

What started as a programming exercise has become the foundation of this very website.

The Idea

I wanted to understand how static websites are generated from Markdown files and how different parts of a rendering system fit together.

This project began during a Boot.dev programming course, where I built a static site generator using Python.

What It Does

The generator reads Markdown files, converts supported Markdown elements into HTML, and inserts the generated content into a shared HTML template.

It currently supports:

  • Headings and paragraphs
  • Bold, italic, and inline code
  • Links and images
  • Ordered and unordered lists
  • Code blocks and blockquotes

The resulting pages share a common stylesheet, allowing the website to maintain a consistent appearance.

What I'm Exploring

I'm continuing to experiment with the generator as I develop this portfolio.

Some areas I'd like to explore further include:

  • Improving Markdown parsing
  • Making page generation more flexible
  • Improving the generated website's structure
  • Understanding the trade-offs involved in building tools from scratch
