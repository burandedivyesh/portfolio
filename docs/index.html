Hi, I'm Divyesh.

Murphy's Law doesn't mean that something bad will happen. It means that whatever can happen will happen.

-- Interstellar (2014)

I'm a curious builder who loves experimenting with technology, exploring ideas, and figuring out how things work.

My journey began in Instrumentation and Control Engineering, but my interest in programming and software gradually led me towards Data Science. I followed that curiosity to pursue a Master's in Data Science at Heriot-Watt University.

Along the way, I've explored everything from machine learning and optimisation algorithms to benchmarking Python against Rust and building my own static site generator.

This website is my little corner of the internet, where I share things I've built, experiments I've tried, and lessons I've learned along the way.

Things I've Built

Some projects start with a problem to solve. Others start with a question I can't quite leave alone. These are a few that have kept me curious.

A Website Built with Its Own Generator

I wanted to understand what happens between writing Markdown and seeing a finished web page. So I built a static site generator and used it to make the site you're reading now. It is still a work in progress, which is part of the fun.

Python, Rust, and the Cost of Doing the Same Work

What changes when two languages tackle the same task? For my Master's dissertation, I explored that question through audio processing, benchmarking, and experiments designed to separate assumptions from evidence.

Learning to Optimise Without a Shortcut

Instead of relying on a ready-made training method, I experimented with particle swarm optimisation to train a neural network. It became a way to explore how simple rules, iteration, and careful testing can lead to surprising behaviour.
